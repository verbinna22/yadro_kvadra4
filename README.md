# Media. Установка библиотек

Устанавливать библиотеки лучше на Linux/WSL

```
sudo apt install libasio-dev zlib1g-dev libssl-dev
wget https://github.com/CrowCpp/Crow/releases/download/v1.2.1.2/Crow-1.2.1-Linux.deb
dpkg -i Crow-1.2.1-Linux.deb
```

# Media. Система сборки

Проект на C++ с системой сборки CMake

## Структура проекта

```
project/
├── main/
│   ├── include/     # Заголовочные файлы основного кода
│   └── src/         # Исходные файлы основного кода
└── CMakeLists.txt   # Файл конфигурации сборки
```

## Требования

- CMake версии 3.5 или выше
- Компилятор C++ с поддержкой стандарта C++23

## Сборка проекта

```bash
mkdir build
cd build
cmake ..
make
```

## Цели сборки

### Основные цели

- **`media`** - стандартная сборка

## Опции компиляции

### Флаги компилятора

Проект использует строгие флаги компиляции:
- `-Wall`, `-Wextra`, `-Wpedantic` - максимальный уровень предупреждений
- Различные специфичные флаги для контроля качества кода

## Запуск
С таймаутом 25 секунд:
```bash
build/media 25
```
С таймаутом 20 секунд (по умолчанию):
```bash
build/media
```
Примечание:
- Программа не следует по символическим ссылкам
- Реализованы все дополнительные задания (при выборе другого каталога .media_files формируется в нём же)
